# CryoChaos video effects

Place video files in this folder. The project copies them into the published
application automatically.

The built-in **Fake Error Code** effect expects:

`Videos/fake-error-code.mp4`

Use an H.264/AAC MP4 for the best compatibility with WPF `MediaElement`.
The video is displayed full-screen on Destiny's monitor, remains
click-through, does not take focus, and plays its audio at full volume.
